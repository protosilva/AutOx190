# AutOx190
AS/400 frontend emulator automation tool - for those pesky, repetitive manual tasks

# Backstory
Autox190 was born out of a need to automate repetitive, time intensive manual data entry tasks, with minimal permissions.
It operates entirely in user space, making use of the built-in utilities at a user's disposal within a standard windows environment; 
it's made with 100% all natural batch files and powershell scripts, and no it's not the prettiest code, but dammit it's functional im trying ok

# Requirements
Autox190 should already have everything it needs to run in any out of the box, updated Windows 10/11 environment assuming you have the AS/400 emulator installed, 
but in case it fails, here's what (iirc) it needs to run-

- Mochasoft TN5250 / AS/400 emulator
- powershell version x
- windows cmd version x
- .NET runtime version x, more specifically with windows forms support
